# Neon Pulse

Neon Pulse is a music download and music streaming platform for discovering, listening to, and downloading royalty-free music, EDM, Lo-fi, Sound effects, and many more.

## Features

- Stream electronic music
- listen to ad-free music
- download royalty-free non-copyright music and sound effects.
- Download tracks instantly
- Filter music by genre and mood
- Responsive user interface
- Feedback and contact pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Netlify

## Live Website

https://neonpulsemusics.netlify.app

## Run Locally

1. Clone the repository:
   git clone <repository-url>

2. Open the project folder.

3. Open `index.html` in your browser.
