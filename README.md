# Neon Pulse 🎧

Neon Pulse is a free, royalty-free music streaming platform for discovering and listening to electronic, pop, ambient, and other original tracks — with a free download library launching soon.

**Live site:** [https://neonpulsemusics.netlify.app](https://neonpulsemusics.netlify.app)

---

## Features

- 🎵 Stream royalty-free music — electronic, pop, ambient, and more
- 🚫 Ad-free listening experience
- 🔍 Filter tracks by genre, mood, duration, and vibe
- ⚡ Custom audio player with playback speed control, volume, and seek
- 📱 Fully responsive UI across devices
- 💬 Feedback form to help shape future updates
- 📩 Contact page with direct email, social links, and location
- ⬇️ Free downloads — coming soon (join the waitlist on the [download page](https://neonpulsemusics.netlify.app/download.html))

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla)
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- Hosted on [Netlify](https://www.netlify.com/)
- Forms handled by [Formspree](https://formspree.io/)

## Run Locally

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project folder.
3. Open `index.html` in your browser — no build step required.
